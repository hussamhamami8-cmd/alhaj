# دليل الحاج 🕋

نسخة واجهة جاهزة للرفع إلى GitHub Pages.

## الصور
ضع الصور المرخصة داخل مجلد `images` بالأسماء:
- `haram.jpg`
- `mina.jpg`
- `arafat.jpg`
- `muzdalifah.jpg`
- `jamarat.jpg`
- `safa-marwa.jpg`

إذا لم توجد الصور سيظهر مكانها تصميم بديل.

## النشر
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## زر الرجوع
التطبيق يستخدم History API، لذلك زر الرجوع داخل التطبيق وزر الرجوع في الهاتف يعملان مع الصفحات والتفاصيل.
